# Python Projects Portfolio 

Welcome to my repository! This is a curated collection of my Python projects, ranging from automation scripts to web applications and data analysis.

##  How to Explore & Download

Each project is completely **standalone**. You can run them locally or download them individually:

### Option 1: Download a single project
Since GitHub doesn't allow downloading individual folders natively, you can use **[DownGit](https://minhaskamal.github.io/DownGit/#/home)** to download just the project you need:
1. Open the folder of the project you want here on GitHub.
2. Copy the URL from your browser's address bar.
3. Paste the link into **DownGit** and click **Download** to get a ZIP archive.

### Option 2: Run locally
1. Clone the entire repository and navigate to the project's directory:
   ```bash
   git clone https://github.com/Trid147/python-portfolio
   cd python-portfolio/Project_Name_1
   ```
2. Read the local `README.md` inside that folder for specific setup and installation instructions.
